# Contributing

Contributions that improve source quality, classification, validation, accessibility, or practical enablement value are welcome.

## Submit a field note

Open a **Field Note** issue and provide the observed change, affected audience, practical adoption implication, and a primary source where available.

## Pull requests

Run `python scripts/validate.py` before submitting changes.

Do not add copied articles, unverifiable claims, promotional affiliate links, or confidential employer information.
